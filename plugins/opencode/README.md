# Mark integrations

Annotate the current diff in the terminal, then return selected notes to the chat input as a Markdown draft. Notes can be questions, observations, or requests. Shift-Q instantly returns all marks to the draft; use the `n` marks list for a selection. Returning marks starts no agent turn; press Enter in chat when ready. Back sends nothing; every invocation starts fresh.

Install a matching Mark executable separately. See the [integration instructions](https://github.com/phongndo/mark/blob/main/docs/integrations.md) for setup, local development, and host limitations. The included [MIT license](LICENSE) applies to this package.
