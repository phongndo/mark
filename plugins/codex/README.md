# Mark integration

Mark lets a person inspect code changes and send selected feedback to the coding conversation that produced them. This package contains the harness entry files, shared review workflow, and local MCP configuration for that connection.

Install Mark first and keep the binary and package versions aligned. Follow the [integration instructions](https://github.com/phongndo/mark/blob/main/docs/integrations.md) for installation, supported review surfaces, and their limits. The included [MIT license](LICENSE) applies to this package.
